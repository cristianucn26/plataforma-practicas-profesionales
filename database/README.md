# Database

Base de datos de la plataforma de gestión de prácticas profesionales.

Motor de base de datos:
- PostgreSQL 16.

Entidades principales:
- Programa.
- Estudiante.
- Empresa.
- Oferta.
- Postulación.
- Tutor.
- Práctica.
- Informe.

Contiene la estructura de las tablas y los datos iniciales del sistema.
